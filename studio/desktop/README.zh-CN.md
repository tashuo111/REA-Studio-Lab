# REA Studio Lab 0.4.0 · Windows 桌面便携版

将整个文件夹解压到你希望保留的位置，双击 `REA Studio Lab.exe`。无需安装 Node.js、启动本地服务器或打开浏览器。请保留整个文件夹，不能单独移动 EXE。支持 Windows x64。

## 使用

1. 点击「开始录屏」，在「整个屏幕」或「应用窗口」中选中目标，再点「开始录制」。不要最小化被录制的窗口。
2. 点击「结束录屏」，内容会进入编辑器。先点击「保存原片」，在系统的另存为窗口中选择位置。
3. 右侧「缩放 → 缩放方式」点击展开「固定焦点 / 跟随鼠标」。本版新录屏会同步记录鼠标轨迹，有有效轨迹时默认启用跟随，范围为整段录屏。两种方式共用开始、结束秒数和倍率；例如从 2 秒到 6 秒，即整个缩放区间为 4 秒，包含平滑进入和退出。固定焦点可以点击预览选择位置；跟随鼠标可以调整平滑度（默认 200 ms，数值小更紧跟，大则更柔和）。
4. 设置背景、留白、圆角、裁剪起点和终点，播放预览。
5. 右侧最上方「导出设置 → 分辨率」可选 720p、1080p、2K / QHD（2560 × 1440）、4K / UHD（3840 × 2160）。点击「导出 WebM」，保持窗口可见并等待实时导出，最后选择保存位置。「保存当前帧」也按所选分辨率输出 PNG。
6. 「保存参数」保存编辑设置与鼠标轨迹，不含视频。以后先导入原片，再「打开参数」即可恢复跟随；原片可改名，但字节内容必须一致。只保存 WebM 原片不会保存可编辑的轨迹；导出合成视频会把跟随效果直接画入视频。

所有视频在本机处理。当前不会自动保存项目，关闭前请保存原片和参数。已有浏览器版的素材不会自动迁移，请使用「保存原片」「保存参数」带到桌面版。

## 当前边界

- 无声录制与预览；视频输出最高 3840 × 2160 / 目标 30 fps / WebM。单次录制和导出最长 2 分钟，缓存上限 256 MiB；高分辨率视频可能先达到缓存上限。录屏到达上限会自动停止并保留原片；导出超限会取消并提示缩短片段。
- 录屏请求最高 4K 的理想尺寸，实际尺寸由屏幕/窗口和系统决定，录制时及素材信息中可见。导出选项不会改变显示器分辨率；低分辨率原片放大到 4K 不会增加真实细节。
- 留白、圆角、阴影与缩放焦点在不同分辨率下保持相同比例。参数格式 v3 保存分辨率与鼠标轨迹；v1 按原来的 720p 恢复，v2 保留已有分辨率，两者都保持固定焦点。导入或录制新素材会保留当前分辨率选择。
- 4K 对性能和内存要求更高。本机验证了短片段输出，未验证长时间 4K 帧率稳定性。
- 单个缩放区间，可选固定焦点或跟随鼠标。旧录屏、外部导入的视频、演示素材没有原生轨迹，跟随选项会禁用并提示重新录制；不会从普通视频中识别鼠标。
- 支持新录制的整个屏幕和普通应用窗口。鼠标离开所选区域、窗口被遮挡或最小化时，镜头保持最后位置；窗口移动时重新计算位置。录制时建议保持窗口尺寸与显示设置不变。特殊窗口、游戏内自绘鼠标、跨显示器 DPI 切换尚未全面验证。
- 轨迹约每 33 ms 请求一次采样，实际间隔取决于系统调度；本机一段 72 秒窗口测试约每秒 21 个采样。与视频开始时间对齐，但不承诺逐帧精确同步。采集异常会保留普通录屏或已有轨迹，并在结束时提示。
- 尚无自动按点击生成缩放片段、多个缩放区间、音频、摄像头和 MP4 导出。
- 参数与原片分别保存。没有安装器、自动更新或代码签名。
- 本版是独立实验原型，与 Screen Studio 官方无隶属关系。目标截图及完整功能尚未取得，不能视为完整复刻。
