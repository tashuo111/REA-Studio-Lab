# REA Studio Lab 0.3.0 · Windows 桌面便携版

将整个文件夹解压到你希望保留的位置，双击 `REA Studio Lab.exe`。无需安装 Node.js、启动本地服务器或打开浏览器。请保留整个文件夹，不能单独移动 EXE。支持 Windows x64。

## 使用

1. 点击「开始录屏」，在「整个屏幕」或「应用窗口」中选中目标，再点「开始录制」。不要最小化被录制的窗口。
2. 点击「结束录屏」，内容会进入编辑器。先点击「保存原片」，在系统的另存为窗口中选择位置。
3. 右侧「手动缩放」中设置开始、结束秒数与倍率；例如从 2 秒到 6 秒，即整个缩放区间为 4 秒，包含平滑进入和退出。点击预览画面可设置焦点。
4. 设置背景、留白、圆角、裁剪起点和终点，播放预览。
5. 右侧最上方「导出设置 → 分辨率」可选 720p、1080p、2K / QHD（2560 × 1440）、4K / UHD（3840 × 2160）。点击「导出 WebM」，保持窗口可见并等待实时导出，最后选择保存位置。「保存当前帧」也按所选分辨率输出 PNG。
6. 「保存参数」只保存编辑设置，不含视频。以后先导入原片，再「打开参数」即可恢复；原片可改名，但字节内容必须一致。

所有视频在本机处理。当前不会自动保存项目，关闭前请保存原片和参数。已有浏览器版的素材不会自动迁移，请使用「保存原片」「保存参数」带到桌面版。

## 当前边界

- 无声录制与预览；视频输出最高 3840 × 2160 / 目标 30 fps / WebM。单次录制和导出最长 2 分钟，缓存上限 256 MiB；高分辨率视频可能先达到缓存上限。录屏到达上限会自动停止并保留原片；导出超限会取消并提示缩短片段。
- 录屏请求最高 4K 的理想尺寸，实际尺寸由屏幕/窗口和系统决定，录制时及素材信息中可见。导出选项不会改变显示器分辨率；低分辨率原片放大到 4K 不会增加真实细节。
- 留白、圆角、阴影与缩放焦点在不同分辨率下保持相同比例。新参数文件保存分辨率；旧版参数文件按原来的 720p 恢复。导入或录制新素材会保留当前分辨率选择。
- 4K 对性能和内存要求更高。本机验证了短片段输出，未验证长时间 4K 帧率稳定性。
- 单个手动缩放区间；尚无自动点击跟踪、多个缩放片段、音频、摄像头和 MP4 导出。
- 参数与原片分别保存。没有安装器、自动更新或代码签名。
- 本版是独立实验原型，与 Screen Studio 官方无隶属关系。目标截图及完整功能尚未取得，不能视为完整复刻。
